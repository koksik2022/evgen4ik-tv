# Evgen4ik TV — редактор IPTV-плейлистов

Свой маленький сервер для IPTV. В браузере, на русском, вы:

- собираете один плейлист из ссылок своего IPTV-провайдера (одного или нескольких);
- переименовываете, прячете, группируете и сортируете каналы, склеиваете дубли;
- делаете отдельные плейлисты со своими ссылками («Детям», «Кухня»…) — с паролем, сроком действия и QR-кодом;
- добавляете бесплатную подборку: каналы России и зарубежная музыка;
- смотрите любой канал прямо в редакторе или открываете его в VLC.

---

## С чего начать — что запускать

1. Распакуйте архив: правой кнопкой по `Evgen4ik-TV.zip` → **«Извлечь всё…»**. Из неоткрытого архива установка не запустится.
2. В распакованной папке дважды щёлкните **`Установить Evgen4ik TV.bat`**.
3. Выберите, куда ставим:

| | Куда ставим | Где работает |
|---|---|---|
| **1** | Этот компьютер с Windows | Только дома и пока компьютер включён |
| **2** | Сервер в интернете (VDS) | Всегда и везде: дома, на даче, в телефоне |
| **3** | Удалить с этого компьютера | — |

**Если Windows предупреждает.** Программа не подписана цифровой подписью, поэтому Windows может спросить «Запустить этот файл?» или показать синее окно «Windows защитила ваш компьютер». Нажмите **«Подробнее» → «Выполнить в любом случае»**. Весь код открыт — его можно посмотреть в `.bat`, `.ps1` и на GitHub.

Папки `1 На сервер (VDS)` и `2 На этот компьютер (Windows)` — те же установщики по отдельности (файлы «ЗАПУСТИТЬ…»). Ими можно пользоваться вместо общего меню.

## Установка на сервер (VDS)

**Что нужно:**
- VDS с **Ubuntu 22.04 / 24.04** или **Debian 12** и доступ root по SSH;
- 1 ядро и 1 ГБ памяти. Для режима с HLS Proxy лучше 2 ГБ и хороший канал: всё видео идёт через сервер;
- домен — по желанию. С ним будет HTTPS, без него всё работает по `http://IP-сервера`.

### Самый быстрый способ — одной командой

Зайдите на сервер по SSH (PuTTY, MobaXterm, Termius или `ssh root@IP-сервера`) и вставьте одну строку:

```
curl -fsSL https://raw.githubusercontent.com/koksik2022/evgen4ik-tv/main/get.sh | sudo bash
```

Если на сервере нет `curl`:

```
wget -qO- https://raw.githubusercontent.com/koksik2022/evgen4ik-tv/main/get.sh | sudo bash
```

Команда скачает установщик, проверит его контрольную сумму (SHA-256) и запустит — дальше те же вопросы, что ниже.
Если GitHub недоступен, загрузчик сам попробует запасной адрес.

Без вопросов, сразу с параметрами:

```
curl -fsSL https://raw.githubusercontent.com/koksik2022/evgen4ik-tv/main/get.sh | sudo bash -s -- --mode direct --access login --yes
```

### Способ 1 — с компьютера на Windows (проще)

1. Откройте папку **«1 На сервер (VDS)»**.
2. Запустите **«ЗАПУСТИТЬ установку на сервер.bat»** и выберите **1**.
3. Введите IP сервера, пользователя (обычно `root`) и порт SSH (обычно `22`). Когда ssh спросит пароль сервера — введите его.
4. Ответьте на вопросы установщика (см. ниже).

Пункт **2** в этом меню — открыть редактор через SSH-туннель, если вы выбрали вход «только через туннель». Пункт **3** — показать ссылки.

### Способ 2 — командой на самом сервере

Скопируйте `evgen4ik-tv-install.sh` на сервер (WinSCP, `scp` или как удобно) и выполните:

```
sudo bash evgen4ik-tv-install.sh
```

Установка занимает 2–5 минут. В конце установщик покажет адрес редактора, логин и пароль, ссылку на основной плейлист и программу передач (EPG). Те же данные сохраняются на сервере в `/root/evgen4ik-tv-доступ.txt`, видны только root.

## Установка на компьютер с Windows

Сервер работает внутри Windows — через встроенную подсистему Linux (WSL2) с Ubuntu. Телевизоры дома открывают плейлисты по адресу компьютера.

**Что нужно:**
- Windows 10 версии 2004 и новее или Windows 11 (лучше 11);
- включённая виртуализация в BIOS (Intel VT-x / AMD SVM) — обычно уже включена;
- учётная запись с правами администратора.

**Как поставить:**
1. Откройте папку **«2 На этот компьютер (Windows)»**.
2. Запустите **«ЗАПУСТИТЬ установку на компьютер.bat»** и согласитесь на права администратора.
3. Если WSL ещё не было, он поставится вместе с Ubuntu 24.04 (~500 МБ):
   - Ubuntu попросит придумать **имя пользователя и пароль Linux** (латиницей);
   - когда появится строка вида `имя@компьютер:~$`, напечатайте `exit` и нажмите Enter;
   - если Windows попросит перезагрузку — перезагрузитесь и запустите тот же файл ещё раз, установка продолжится.
4. Ответьте на вопросы: сделать сеть Wi-Fi/Ethernet **частной (домашней)** — **да**, это нужно телевизорам. Домен для дома не спрашивается.

**Что установщик настраивает сам:**
- systemd в Ubuntu — чтобы службы запускались автоматически;
- сеть: на Windows 11 — «зеркальный» режим WSL. Если он на компьютере не включился (так бывает с VPN-адаптерами), установщик сам переходит на проброс портов. На Windows 10 — сразу проброс портов;
- брандмауэр: входящие порт 80 и второй порт — 8080 или следующий свободный (на нём редактор в режиме с HLS Proxy), **только для частной сети**;
- автозапуск при входе в Windows (задача «Evgen4ik TV (WSL)»): поднимает Ubuntu и держит её включённой;
- по желанию — отключение спящего режима при питании от сети.

**Обязательно:** закрепите за компьютером IP-адрес в роутере (резервирование DHCP). Иначе после смены адреса ссылки в телевизорах перестанут работать. Если адрес всё же сменился — запустите установку ещё раз и выберите «обновить».

**Команды на компьютере** выполняются через WSL, например:

```
wsl -d Ubuntu-24.04 -u root -- e4tv info
wsl -d Ubuntu-24.04 -u root -- cat /root/evgen4ik-tv-доступ.txt
```

**Удаление:** «Удалить с компьютера.bat» в той же папке. Удаляются автозапуск, правила брандмауэра, проброс портов и программа внутри Ubuntu. Саму Ubuntu не трогает: удалить её целиком (со всеми файлами внутри) можно командой `wsl --unregister Ubuntu-24.04`.

## Вопросы установщика

| Вопрос | По умолчанию | Что значит |
|---|---|---|
| Адрес для плееров (если сервер за роутером) | домашний IP | Домашний — только в этой сети. Внешний — откуда угодно, но на роутере нужен проброс портов и белый IP |
| Как идут потоки | **2 — без HLS Proxy** | См. «Режимы» ниже |
| Сколько каналов одновременно (только с HLS Proxy) | **не спрашивается — «Авто»** | Редактор сам берёт лимит провайдера, которого вы добавите в «Источниках» (до этого — 3). Задать вручную: в редакторе, `e4tv streams N` или `--streams N` при установке; **0 — без лимита** |
| Домен | нет | Нужен для HTTPS. Запись A домена должна указывать на IP сервера. Дома не спрашивается |
| E-mail | нет | Для писем Let's Encrypt о сертификате |
| Вход в редактор | **логин и пароль** | Или «только через SSH-туннель» — тогда редактор вообще не виден из интернета |
| Логин / пароль | `admin` / придумать автоматически | Пароль — не короче 6 символов |

**Если на сервере уже что-то стоит** (например, WEB-прокси Telegram или другой сайт на портах 80/443/8080), установщик 2.9+ сам
подберёт свободные порты и скажет об этом: плейлисты и HLS Proxy — на **8090**, редактор — на **8091**
(адрес будет вида `http://IP:8091/`). Домен на таком сервере не подключается — для него нужны свободные 80 и 443.
Задать порты вручную: `--port 8090` (плейлисты) и `--alt-port 8091` (редактор в режиме с HLS Proxy).
При обновлении с 2.8, где nginx не запустился из-за занятого порта, достаточно запустить установщик ещё раз и выбрать «обновить».

### Режимы

| | Без HLS Proxy (2) | С HLS Proxy (1) |
|---|---|---|
| Видео идёт | от провайдера прямо в плеер | через ваш сервер |
| Нагрузка на сервер | почти нет | весь видеотрафик |
| В плейлистах | прямые ссылки провайдера (в них ваш ключ у провайдера) | ссылки вашего сервера, данные провайдера скрыты |
| Для провайдера | каждый телевизор — отдельное устройство | одно устройство, лимит держит HLS Proxy |
| Резервные потоки | плеер берёт первый | HLS Proxy сам переключается, если поток упал |
| Программа передач (EPG) | общая (it999) | своя, с вашего сервера |
| Подходит, если | у каждого свой провайдер | один провайдер на семью, нужны резерв и скрытые ссылки |

HLS Proxy работает только на процессорах x86_64.

## Первые шаги в редакторе

1. Откройте адрес редактора и войдите.
2. **Источники** — при первом входе редактор откроется сразу здесь:
   - выберите своего провайдера: подскажет, где в личном кабинете взять ссылку, и покажет его лимит устройств;
   - вставьте ссылку на плейлист (или данные Xtream, или загрузите файл `.m3u`) → **«Добавить»**;
   - нажмите **«Сохранить и применить»**.
3. Через минуту каналы появятся в **«Группах и каналах»**. Здесь их можно прятать, переименовывать, перетаскивать, склеивать дубли и смотреть (кнопка ▶).
4. **Объединённые плейлисты**:
   - внизу — ссылка на **основной плейлист** и на программу передач. Вставьте их в плеер: Televizo, OTT Navigator, TiviMate, Smart IPTV, VLC…;
   - **«+ Новый плейлист»** — своя подборка со своей ссылкой, паролем, сроком действия, нумерацией каналов и QR-кодом для телевизора.

Плейлист пересобирается сам каждое утро: провайдеры меняют ссылки. Подборки обновляются раз в час.

### «Сохранить» или «Сохранить и применить»

- **«Сохранить»** — меняются только ваши подборки. Просмотр на телевизорах не прерывается.
- **«Сохранить и применить»** — полная пересборка: источники, группы, названия. С HLS Proxy просмотр прервётся на несколько секунд.

В «Источниках» есть подсказки для 13 провайдеров: где взять ссылку и сколько устройств разрешено.

| Провайдер | Лимит | Заметка |
|---|---|---|
| Sharavoz TV | 2 | При третьем просмотр блокируется на всех на 15 минут |
| TV Team | 2 | Можно докупить до 20 |
| Glanz TV | 3 | |
| VipLime | 2 | |
| AntiFriz TV | 2 | Только с одного IP-адреса |
| ip-tv.best | 2 | Данные из одного обзора |
| EDEM | 2 | Если ссылкой пользуется кто-то чужой — смените ключ в кабинете |
| BitTV | 3 | |
| Cbilling | 2 | По разным обзорам от 1 до 3 |
| RUTV.VIP | неизвестен | Есть медиатека: `vod.m3u` — фильмы, `series.m3u` — сериалы |
| Yosso | неизвестен | Есть медиатека, до 10 устройств за доплату |
| IPTV Online | 2 | До 5 за доплату |
| iLook TV | 2 | +2 через Stalker Portal с платной подпиской |

Лимиты взяты из обзоров на ноябрь 2026 года. Точные — в вашем личном кабинете или у поддержки провайдера.

**Внизу «Источников» — «Сколько каналов одновременно»** (режим с HLS Proxy). Три варианта:
- **Авто** (по умолчанию в новых установках) — наименьший лимит из включённых провайдеров списка выше. Источник не из списка считается с лимитом 3 «на всякий случай». Если это сторонний (бесплатный) плейлист без ограничения устройств — отметьте у него в списке «без лимита устройств». Если все источники такие, лимита нет;
- **Своё число** — кнопка «Поставить N» подставит лимит ваших провайдеров;
- **Без лимита** — только если все плейлисты сторонние.

Применяется по «Сохранить и применить». Без HLS Proxy там памятка: сколько телевизоров могут смотреть одновременно.

Для провайдера, которого нет в списке, подойдёт «Любая M3U-ссылка» или «Xtream Codes».

**Ссылка из кабинета — это ваш личный ключ подписки.** Не выкладывайте её в чаты: кто её получит, будет смотреть за ваш счёт, а лимит устройств закончится у вас.

## Бесплатная подборка

Плитка **«Бесплатно: Россия + зарубежная музыка»** в «Источниках».

- Сервер сам собирает её из открытых списков iptv-org и Free-TV.
- Российские каналы разложены по группам «РУ: Эфирные», «РУ: Новости», «РУ: Кино», «РУ: Детские» и т.д.
- Зарубежная музыка разложена по регионам: «США и Канада», «Европа», «Латинская Америка», «Азия», «Африка».
- Дубли убраны. Сервер раз в 6 часов проверяет каждую ссылку и оставляет только рабочие. Сколько их сейчас, видно на плитке.
- Подборка не входит в основной плейлист: её каналы попадают только в ваши подборки. В плейлисте: «Откуда брать каналы» → подборка → отметьте группы или каналы.
- Первая сборка занимает 2–5 минут.

### Клиенты

Раздел **«Клиенты»** — для тех, кому вы даёте доступ (родные, друзья, телевизор на даче).

- У каждого клиента **своя личная ссылка**. В неё собираются каналы отмеченных ему плейлистов, без повторов. Можно отмечать и выключенные плейлисты: своей ссылки у них нет, а клиенту они достаются.
- **Срок:** «+1 месяц», «+3 месяца», «+1 год» или «Бессрочно». После срока ссылка перестаёт работать сама. За 7 дней клиент подсвечивается в списке.
- **Выключить** — ссылка перестаёт работать сразу после сохранения. **Новая ссылка** — если ссылку кому-то переслали.
- **Подключение** — первый блок на странице клиента: статус и срок, короткая ссылка (главная), длинная (запасная), EPG, QR сразу на странице, «Копировать сообщение», «Xtream Codes ▾» (сервер, логин, пароль), «Новая ссылка» и «⋯» → «Сделать копию» / «Удалить клиента». Удалить клиента можно и из списка: «⋯» в конце строки.
- **Коротко** — вторая, короткая ссылка клиента (`…/pl/sasha-7x.m3u8`), удобно продиктовать или набрать на телевизоре. Длинная продолжает работать, заходы, срок и разрешённые IP — общие. «Предложить» добавляет к имени пару случайных знаков, чтобы ссылку не угадали. «Новая ссылка» убирает и короткую.
- **Каналов одновременно** (только с HLS Proxy): у каждого клиента свой логин в HLS Proxy со своим лимитом. Общий лимит провайдера HLS Proxy всё равно не превысит. Когда добавляете, выключаете клиента или меняете лимит, HLS Proxy перезапускается — просмотр прервётся на несколько секунд.
- **Без 18+** — детский режим для клиента.
- **Клиент без плейлиста** — в его строке сразу выбор плейлиста («+ выбрать плейлист…», в том числе «новый личный») и «Из файла…» (каналы файла станут своими каналами клиента); в карточке — «Создать личный плейлист» и «Загрузить из файла с ПК».
- **Открыть плейлист клиента** — нажмите на плейлист в строке клиента (или в карточке): откроется его редактор, вверху — «← Клиент …».
- **Личный плейлист** — в карточке клиента у общего плейлиста кнопка **«Сделать личным»**: копия только для этого клиента ставится вместо общего. Правки в ней касаются только его. Личные плейлисты не показываются в «Объединённых плейлистах», своей ссылки у них нет, при удалении клиента удаляются.
- **Общий плейлист** — «Включён» отвечает за его собственную ссылку, «Клиентам» — можно ли отмечать его у клиентов (выключили — клиенты перестают получать его каналы). В списке видно, у скольких клиентов он отмечен; перед удалением — предупреждение.
- **Каналы клиента** — его личный список прямо в карточке: выключить канал, добавить канал из основного плейлиста, добавить свой канал по ссылке, поменять ссылку у любого канала, загрузить каналы **из файла .m3u с ПК** (станут своими каналами клиента; все каналы файла убираются одной кнопкой). Правки действуют только на этого клиента, сами плейлисты не меняются. Свои ссылки и свои каналы клиента подчиняются настройке «Скрывать ссылки провайдера» (ниже): при «Полностью» сервер сам добавляет их в HLS Proxy, и они считаются в лимите клиента.
  - **Откуда поток** — у каждого канала одна строка: источник, ссылка (полная — при наведении) и кнопка режима. «Авто · 2 резерва» — как в плейлисте: через HLS Proxy, при сбое основного источника берётся резервный (тот же канал у другого источника). В меню кнопки: «Только <источник>», «Своя ссылка…» и «Проверить поток». Режимы, отличные от «Авто», подсвечены; над таблицей — «Настроено вручную: N», «Показать только их» и «Все на «Авто»».
  - **Метки состояния**: «источник не отвечает» — источник не отдал каналы при последней сборке; «основной не отвечает» — основной упал, HLS Proxy берёт резерв. Своя ссылка проверяется при вводе («отвечает» / «не отвечает»); udp и rtmp не проверяются.
  - **Массово**: отметьте каналы галочками — над таблицей появятся «Поток: Авто / только <источник>» + «Применить», «Выключить», «Включить». Каналы, у которых нет выбранного источника, не меняются (редактор скажет сколько).
  - **▶ Посмотреть** (кнопка ▶ рядом с режимом) — канал в плеере редактора так, как его получит клиент. Это тоже поток к провайдеру; не каждый поток играет в браузере — тогда «Открыть в VLC».
  - **ⓘ** в заголовке колонки «Поток» — шпаргалка по режимам «Авто», «Только…», «Своя ссылка» и меткам.
- **Вход через Xtream Codes** — у клиента есть сервер, логин и пароль: в TiviMate, IPTV Smarters, OTT Navigator выберите «Xtream Codes» и введите их вместо ссылки. Каналы те же, что в ссылке клиента; срок, выключение и разрешённые IP действуют. Если канал не включается — в плеере поставьте формат потока HLS (m3u8). Архив передач через Xtream работает, фильмы и сериалы не поддерживаются.
- **Разрешённые IP** — ссылка и вход Xtream открываются только с указанных адресов (можно сеть, например `192.168.1.0/24`). Ограничение действует на получение плейлиста, а не на сами потоки: уже скачанный файл плейлиста продолжит работать с любого адреса — для этого есть «Новая ссылка» (меняет и логин клиента в HLS Proxy). Правила для nginx — в `/etc/nginx/e4tv-acl.conf`.
- **Порядок каналов** — в «Каналах клиента» перетаскиванием за ⠿.
- **Смотрят сейчас** (режим с HLS Proxy) — кто прямо сейчас получает видео через HLS Proxy (за последние 30 секунд ему ушло в среднем от 8 КБ/с; открытая страница статуса HLS Proxy или редактор зрителем не считаются), сопоставлено с клиентами по их последнему IP; обновляется раз в 20 секунд. Это оценка по IP: если два клиента за одним роутером — их не различить. На домашнем ПК с WSL все подключения приходят с одного адреса Windows, поэтому там это не работает. Через Xtream видно ещё и последний включённый канал.
- **Сообщение клиенту** (в строке клиента меню «⋯») — готовый текст с инструкцией и ссылкой, остаётся скопировать и отправить. Шаблон можно поменять (подстановки `{ИМЯ}`, `{СРОК}`, `{ССЫЛКА}`, `{EPG}`, `{ПОТОКИ}`).
- **Активность** — когда плеер последний раз скачивал плейлист, какой это плеер и IP, заходы по дням за неделю. Берётся из журнала nginx `/var/log/nginx/e4tv-pl.log` раз в минуту. Какие каналы смотрели — не записывается.
- **Скачать список (.csv)** — таблица клиентов для Excel.

### Скрывать ссылки провайдера

Меню слева «Настройки» → «Ссылки и логотипы» — одна настройка на всё (на страницах «Клиенты» и «Объединённые плейлисты» — строка с текущим вариантом и кнопкой «Изменить»). У отдельного плейлиста или клиента можно «Сделать иначе».

| Вариант | Путь видео | Ссылка провайдера | Лимит клиента | Трафик сервера |
|---|---|---|---|---|
| 🔒 **Полностью** (только с HLS Proxy) | Провайдер → HLS Proxy → Плеер | не видна | работает | да |
| 📄 **Только в файле** | Провайдер → Плеер, адрес выдаёт сервер | не видна в файле, видна в сетевых запросах плеера | нет | нет |
| 🔓 **Не скрывать** | Провайдер → Плеер | в файле | нет | нет |

По умолчанию: с HLS Proxy — «Полностью», без него — «Только в файле». В «Дополнительно»: «Логотипы через сервер» (картинки каналов с адреса вашего сервера) и что делать со своей ссылкой, которую не удалось пустить через HLS Proxy (например, udp/rtmp). Под карточкой плейлиста и клиента видно, сколько каналов в последней сборке пошло каким способом.

**Формат потока** (там же, «Дополнительно», только с HLS Proxy): **HLS (.m3u8)** — плеер сам качает куски, стандартный вариант и выбор по умолчанию для новых установок; **MPEG-TS (.mpeg)** — один сплошной поток, для старых Smart TV. Переключатель меняет галку «MPEG-TS» у всех логинов HLS Proxy (после «Сохранить» он перезапустится). Плеерам Xtream формат подстраивается сам: просят `.ts` — получают MPEG-TS, `.m3u8` — HLS.

### Логотипы каналов

Откуда берётся картинка канала, по порядку:

1. **Источник** — `tvg-logo` из плейлиста провайдера.
2. **Тёзка** — у «ТНТ4 HD», «ТНТ4 orig», «Пятый канал (+2)» своей картинки нет — берётся у канала с тем же названием без HD/orig/+N.
3. **Открытые базы** (галка «Логотипы из открытых баз» в «Настройки» → «Ссылки и логотипы», по умолчанию выключена): it999 (картинки из телегида), затем [iptv-org/database](https://github.com/iptv-org/database), затем [tv-logo/tv-logos](https://github.com/tv-logo/tv-logos). Сопоставление по названию канала; перед тем как поставить картинку, сборка проверяет, что по ссылке действительно картинка (битая — берётся следующая база). Базы скачиваются при сборке не чаще раза в сутки.
4. **HLS Proxy** — если картинки всё ещё нет, он может подставить свою; редактор показывает её же.

В карточке канала (🔗) видно, откуда логотип сейчас. Там же можно задать свою картинку или нажать **«Без логотипа»** — у канала не будет картинки ни из источника, ни из баз, ни от HLS Proxy (в плейлист ставится пустая картинка с вашего сервера).

### Телегид

«Настройки» → «Телегид»:

- **Последнее обновление** и **«⟳ Обновить сейчас»** (режим с HLS Proxy): HLS Proxy скачивает и разбирает телегид за 1–3 минуты; сам он обновляет его в 8:00 и 23:00. Если HLS Proxy перезапустится посреди скачивания (например, после сборки), запрос повторится сам в течение получаса.
- **Источники** — ссылки XMLTV (`.xml` / `.xml.gz`) по одной в строке, до 5. Пусто — как при установке (it999). С HLS Proxy несколько источников он объединяет; без HLS Proxy плеер получает их списком в шапке плейлиста. Коды каналов (поле «Программа (EPG)» в карточке канала) подбираются по it999 — у другого источника свои коды.
- **Хранить прошедшие передачи, дней** (1–14) — для архива.

Смена источников или срока — «Сохранить»: HLS Proxy перезапустится на несколько секунд и сразу скачает телегид. Как это устроено: редактор пишет правила, `lists.py` (root) переносит их в `local.json` HLS Proxy, а «Обновить сейчас» — вход администратором в HLS Proxy и `/fetchepg` (то же, что кнопка «Fetch EPG» в его панели).

### Уведомления в Telegram
Раздел **«Уведомления»**: бот пишет вам, когда у клиента через 3 дня заканчивается срок, сборка завершилась с ошибкой (и когда снова в порядке), источник перестал отдавать каналы, клиент зашёл с нового IP. Проверка — раз в 5 минут (служба `e4tv-notify.timer`).
1. Telegram → **@BotFather** → `/newbot` → скопируйте токен (лучше отдельный бот, не тот, которым пользуется другая программа).
2. Вставьте токен, напишите боту любое сообщение, нажмите «Найти чат» и выберите себя → «Сохранить» → «Отправить пробное».

Токен хранится только на сервере (`/var/lib/evgen4ik-tv/editor/telegram.json`, права 600), не попадает в правила и резервные копии. Проверка с сервера: `e4tv notify-test`. Нужна связь сервера с `api.telegram.org`.

### Резервная копия в Telegram и восстановление
«Уведомления» → «Резервная копия в Telegram»: раз в сутки (и по кнопке «Отправить копию сейчас») бот присылает файл `.e4b` — источники, плейлисты, клиенты и загруженные файлы, зашифрованные паролем копии (AES-256, `openssl`). Пароль сохраните в менеджере паролей: без него копию не открыть. Восстановить: «История и копии» → «Восстановить из файла…» → пароль; текущие настройки перед этим сохраняются в «Резервных копиях».

### Личная страница клиента
`https://…/my/<длинная ссылка клиента>` — клиент сам видит срок, ссылку (короткую, если есть), QR, EPG, вход Xtream и как подключить. Открывается без входа в редактор, только по длинной ссылке. В «Подключении» у клиента — «открыть ↗» и «Копировать»; в шаблоне сообщения — `{СТРАНИЦА}`.

### Массовые действия с клиентами
Галочки слева в списке клиентов → «+1 месяц», «+3 месяца», «Включить», «Выключить», «Скопировать сообщения» (всем выбранным одним текстом), «Удалить…».

### Подключить домен (HTTPS)
Кнопка «Подключить домен…» в красной полосе «Вход по http»: запись A домена → «Проверить» → «Подключить». Сервер получит сертификат Let’s Encrypt и перенастроится (служба `e4tv-domain`, журнал `/var/log/e4tv-domain.log`; то же с сервера: `sudo e4tv domain tv.example.com you@mail.ru`). **Ссылки клиентов сменятся на https://домен…** — старые перестанут работать, разошлите новые сообщения.

### Удалить канал
Канал перестал работать или не нужен — удалите его, не перебирая плейлисты:
- «Группы и каналы» → 🗑 у канала, или отметьте несколько галочками → «Удалить…», или 🔗 → «Удалить канал»;
- «Проверка потоков» → «Удалить» у канала или «Удалить нерабочие (N)…» сразу все, что не ответили.

Канал пропадает из основного плейлиста, всех объединённых плейлистов и у всех клиентов. Канал провайдера при следующей сборке пришёл бы снова, поэтому он скрывается насовсем — вернуть: фильтр «Скрытые и удалённые» → 👁. Свой канал удаляется полностью.

### Основной источник у канала
Если канал есть у нескольких источников: 🔗 у канала → «Основной источник». Остальные остаются резервом.

### Сдвиг программы у канала
Если у канала телегид идёт не по времени (канал «+2», другой часовой пояс): «Группы и каналы» → 🔗 у канала → **«Сдвиг программы»**, часов (от −12 до +14, шаг 0,5). В плейлист пишется `tvg-shift` — его учитывают многие плееры, но не все: если сдвиг не виден, в настройках плеера поищите «сдвиг телегида».

### Резервные потоки
Одинаковые каналы разных источников склеиваются: первый — основной, остальные — резерв, HLS Proxy сам переключится, если основной не отвечает. Какой источник основной — «Источники». У отдельного канала: 🔗 → ссылки по одной в строке, первая — основная.

### Канал перестал работать

- **Где видно.** «Обзор» → «Не открылось у клиентов» (за сутки, только каналы, которые не запустились) и «Журнал» (за двое суток, ещё и перебои — когда не скачались куски видео, а канал шёл): каналы, которые HLS Proxy не смог взять у провайдера, с причиной по-русски — ошибка 404/502, источник не ответил вовремя, слишком медленно, просроченный сертификат. Берётся из журнала HLS Proxy раз в минуту (`lists.py --activity`); переключение зрителем на другой канал ошибкой не считается, ссылки с ключами в сводку не попадают. Кто именно из клиентов включал канал — HLS Proxy в журнал не пишет. Ещё — «Проверка потоков»: сервер сам проверяет все каналы.
- **Скрыть запись.** ✕ у записи или «Скрыть все» в заголовке — запись не показывается, пока канал снова не сломается (новая ошибка — запись вернётся сама). «Показать скрытые» внизу блока — посмотреть и «Вернуть». Скрытое хранится на сервере, видно из любого браузера.
- **Как заменить.** «Заменить ссылку» у канала в «Проверке потоков» или на «Обзоре»: поле со ссылками канала (первая — основная, остальные — запасные) и тот же канал у других ваших провайдеров и у тёзок (HD, orig, +N) — «↑ основной» ставит ссылку первой. «Проверить ссылки» → «Готово» → «Сохранить и применить».

### Архив передач

Если у провайдера есть архив, клиент смотрит прошедшие передачи прямо в плеере — в любом из трёх вариантов выше и через Xtream Codes. Плеер дописывает к ссылке время записи (`?utc=…&lutc=…`), сервер передаёт его провайдеру.

У склеенных каналов (одно название из нескольких источников) запрос записи уходит главному источнику. Если у него архива нет, отметка архива у канала снимается — чтобы клиент не видел архив, который не откроется.

### Порядок групп в плеере

Каждая группа в плейлисте идёт одним куском, **«18+»** — всегда в самом конце. Каналы со сдвигом времени («Пятый канал (+2)», «+4 (Алтай)») в группе «Эфирные: часовые пояса» стоят рядом по каналу и по возрастанию часов. Свой порядок групп — перетаскиванием в «Группах и каналах»; если у листа задан свой порядок каналов, он не меняется.

### Как устроен редактор

- **Обзор** — главная: «Всё работает» или что не так, когда была и будет сборка, когда обновлён телегид; плитки-переходы, заходы за неделю, кто смотрит сейчас, источники и сроки клиентов.
- **Главная кнопка страницы** — справа от заголовка («+ Новый клиент», «+ Новый плейлист»).
- **Полоса сохранения** внизу появляется, только когда есть несохранённое, и пишет, что изменено. «Пересобрать» без правок — на «Обзоре».
- **В строках** клиентов и плейлистов — частые действия («Ссылка», «QR»), остальное в меню «⋯»; «Выключить» и «Удалить» спрашивают подтверждение.
- **Плитки на «Клиентах»** работают как фильтры.

### Справка в редакторе

Пункт меню **«Справка»**: с чего начать, что за что отвечает и пошаговые инструкции. У заголовков карточек — значок **«?»** с короткой подсказкой.

### Свой плейлист из файла

В объединённом плейлисте, в блоке «Источники», можно не только вставить ссылку, но и нажать **«Из файла…»** и выбрать `.m3u` / `.m3u8` с компьютера (до 30 МБ). Каналы появятся слева в «Откуда брать каналы», дальше — как обычно. Файл сам не обновляется: чтобы обновить, загрузите его заново.

Если на сервере включён VPN, часть российских каналов с ограничением по стране может не пройти проверку.

## Плеер: ▶ и «Открыть в VLC»

У каждого канала есть кнопка **▶** — канал откроется в окне прямо в редакторе.

- Если браузер не может показать поток (DASH, редкие форматы), нажмите **«Открыть в VLC»**. Скачается файл `.m3u` с этим каналом, он откроется в VLC.
- Каналы основного плейлиста в режиме с HLS Proxy играют через HLS Proxy, поэтому лимит действует и здесь.
- **Просмотр в редакторе и в VLC — это тоже поток к провайдеру.** Если на телевизорах уже смотрят столько каналов, сколько разрешает лимит, канал в редакторе не откроется. Плеер так и напишет: «превышен лимит». Закрывайте плеер и VLC после просмотра — поток освободится.
- Каналы бесплатной подборки лимит провайдера не тратят.

## Команды на сервере

| Команда | Что делает |
|---|---|
| `e4tv info` | Ссылки: редактор, основной плейлист, EPG, панель HLS Proxy |
| `e4tv status` | Работают ли службы, итог последней сборки |
| `e4tv passwd` | Сменить логин и пароль редактора (забыли пароль — сюда) |
| `e4tv token` | Новая ссылка основного плейлиста, если старая засветилась. Старая сразу перестаёт работать — в телевизорах нужно вставить новую. Ссылки плейлистов из редактора меняются там кнопкой «Новая ссылка» |
| `e4tv rebuild` | Пересобрать плейлист прямо сейчас |
| `e4tv streams` / `e4tv streams 2` / `e4tv streams 0` | Показать / задать вручную, сколько каналов одновременно (режим с HLS Proxy); `0` — без лимита. Выключает «Авто» — вернуть можно в редакторе |
| `e4tv update` | Обновить до последней версии с GitHub (то же делает кнопка «Обновить» внизу слева в редакторе) |
| `e4tv logs` | Журнал, если что-то не так |
| `e4tv uninstall` | Удалить программу (данные останутся) |
| `e4tv uninstall --purge` | Удалить вместе с данными |

На компьютере с Windows перед командой добавляйте `wsl -d Ubuntu-24.04 -u root --`.

## Обновление и смена настроек

Запустите установку ещё раз — тем же способом, что и в первый раз:

- **1 — обновить программу**: правила, плейлисты, пароли, лимит каналов сохранятся;
- **2 — изменить настройки**: режим, домен, способ входа.

**Пароль редактора в `/root/evgen4ik-tv-доступ.txt`.** Сам пароль на сервере хранится только в виде хеша, поэтому установщик переносит строку «Пароль:» из прошлого файла доступа. С 3.5.1 она сохраняется при обновлении, при смене способа входа на SSH-туннель и обратно, а `e4tv passwd` сам записывает новый логин и пароль в этот файл.

Если после обновления 2.8 → 2.9 в файле нет пароля или стоит «(прежний; забыли — смените: e4tv passwd)», восстановить прежний пароль из файла нельзя: его там уже нет. Если вы его помните — входите как раньше. Если нет — задайте новый командой `sudo e4tv passwd` (Enter — придумать автоматически), он появится в файле.

## Безопасность

- В редактор входят по логину и паролю. После 5 неверных попыток с одного адреса — пауза 15 минут. После 30 неверных попыток со всех адресов за 15 минут — общая пауза.
- Ссылки плейлистов длинные и случайные. На любой плейлист можно поставить пароль (плеер спросит логин `tv` и пароль) и срок действия.
- В режиме без HLS Proxy в плейлисте видны ссылки провайдера с вашим ключом. Не публикуйте такие ссылки в открытом доступе.
- Плеер в редакторе открывает только адреса из ваших собственных плейлистов и только после входа.
- Обычно провайдеры разрешают одну подписку на одно домохозяйство. Друзьям нужны свои подписки.

## Если что-то не так

| Проблема | Что сделать |
|---|---|
| Не открывается редактор (сервер) | `e4tv status`. Проверьте, что у хостера открыты порты 80/443 (с HLS Proxy ещё 8443 или 8080) |
| Не открывается редактор / плейлист с телевизора (компьютер) | Сеть Windows должна быть **частной**. Компьютер включён и вы вошли в Windows. IP компьютера не поменялся — если поменялся, запустите установку ещё раз и выберите «обновить» |
| Каналы не запускаются, на компьютере включён VPN в режиме TUN | HLS Proxy ходит к провайдеру через VPN. Выключите TUN или пустите адрес провайдера напрямую |
| Не выдался сертификат | Проверьте запись A домена и запустите установщик снова (пункт 2) |
| «Слишком много попыток» при входе | Подождите 15 минут или выполните `systemctl restart e4tv-editor` |
| Провайдер заблокировал просмотр | Превышен лимит устройств. Уменьшите «Сколько каналов одновременно» до лимита провайдера, закройте лишние плееры |
| Канал не показывается в плеере редактора | Нажмите «Открыть в VLC» |
| Каналов стало намного меньше | Источник «похудел». Редактор сам возьмёт прошлую рабочую копию и покажет предупреждение. Если источник уменьшили вы сами — нажмите там «Принять новые данные» |
| Бесплатная подборка не появляется | Первая сборка — 2–5 минут. Нажмите «Сохранить» и откройте подборку позже |

## Сторонние программы и списки

- **HLS Proxy** — программа стороннего автора. Установщик скачивает её с сайта автора (hls-proxy.com) и в себе не содержит. Условия использования — на сайте автора.
- **hls.js** и **mpegts.js** (плеер в редакторе) — лицензия Apache 2.0. Тексты лицензий лежат рядом с программой: `/opt/evgen4ik-tv/lib/`.
- Бесплатная подборка собирается из открытых списков проектов **iptv-org** и **Free-TV** на GitHub. Сами каналы принадлежат их владельцам.

## Для разработчика

- Автотесты: `python3 tests/run_tests.py` (только стандартная библиотека Python, для проверки страницы нужен `node`). На GitHub они запускаются сами при каждом изменении (Actions → «Тесты»).
- После правок в `src/` и `install.sh` — `bash make-bundle.sh`, иначе тест «установщик собран из текущего install.sh» упадёт.
- Обновление по кнопке: редактор пишет `update.trigger`, служба `e4tv-update` (root) выполняет `e4tv update`; журнал — `/var/log/e4tv-update.log` (только root).
- Архив HLS Proxy сверяется с `HLSP_SHA256` в `install.sh`, если она задана.
